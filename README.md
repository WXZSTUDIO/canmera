# canmera

浏览器端实时电影感 Log 拍摄 PWA（纯静态 ES Modules + WebGL，无需构建）。

## 界面
专业摄影机布局：顶部参数栏（L/R 音频电平 · 模式 · 分辨率·帧率 · Log 徽标 · 剩余时长/存储），
取景器带参考线与镜头焦距条，底部 7 个专业控件（前置/对焦/白平衡/感光/快门速度/曝光/设置），中央快门键。

## 功能
- 实时影调（8 套）：中性 / 标准·澳门 / 标准·开罗 / 标准·拉普兰 / 标准·洛杉矶 / Log·云梦 / Log·伊犁 / Log·清迈
- 白平衡：色温 + 色调（洋红↔绿）独立调整
- 半自动曝光：ISO 与快门速度可独立锁定，自动最慢 1/30s，快门 1/1000s~1s（慢快门带运动模糊）
- 高亮增益 (HDR) / SDR 肩部兼容
- 麦克风：L/R 音频电平表 + 录影收声
- 照片分辨率（720p/1080p/2K/4K）· 视频帧率（24/25/30/60）
- 取景参考线 · 横滑切换影调 · 影调排序 · 闪光灯 · 导入本地图片套影调
- 人脸识别/二维码扫描（依赖浏览器 FaceDetector / BarcodeDetector，缺失时提示不支持）

## 运行
```
python3 -m http.server 8123
# 打开 http://localhost:8123 （摄像头/真机需 localhost 或 HTTPS）
```

## 网页端不支持
iPhone 18 Pro 可变光圈、前置方形传感器横竖切换、硬件级 Log 编码（此处以影调模拟）。
